# Промпт: диагностики — BAI + интерпретации результатов

## Цель
1. Добавить методику **Шкала тревоги Бека (BAI)** по образцу результата `https://psytests.org/result?v=depT1u` (psytests.org/depr/bai).
2. Для **всех** runnable-методик в каталоге усилить краткую интерпретацию на экране результатов:
   - клиент (`public/diagnostics_result.html` + карточка);
   - специалист (`app/diagnostics_result.html` + CRM-карточка).
3. В **начало каждой** overall-интерпретации — обязательный дисклеймер в духе:
   > Психологическая диагностика не ставит целью поставить диагноз. Результаты носят предположительный характер и их нужно обсуждать с психологом.

## Источники интерпретаций (проверенные / стандартные пороги)
- BAI (Beck Anxiety Inventory): пороги как на psytests / распространённые клинические срезы 0–21 / 22–35 / 36–63.
- BDI, BHS, WCQ, Schmischek, OSOP: опираться на уже заложенные в `catalog.py` / `sop.py` шкальные бэнды; уточнить `interpretation.overall` и текст бэндов, не выдумывать «диагнозы».
- Сохранить/усилить `DISCLAIMER_RU` и `crisis_hint` где уместно.

## Технические ограничения
- Регистрация в `_REGISTRY` (`app/diagnostics/catalog.py`).
- Паттерн как у BDI: items + `score_sum_total` или dedicated scorer + bands.
- Не трогать auth/CRM/timezone/мини-апп без необходимости.
- Тесты: registry + scoring bounds + disclaimer prefix в overall.
- После деплоя интерпретация должна быть видна и клиенту, и специалисту из одного scored payload.

## Критерий готовности
- `bai` в `list_tests(only_runnable=True)`.
- На результате любого теста overall начинается с дисклеймера.
- У BAI корректные бэнды и краткая интерпретация по набранным баллам.
