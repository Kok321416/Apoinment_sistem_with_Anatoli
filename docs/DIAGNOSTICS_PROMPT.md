# Диагностика на профиле специалиста — спецификация проекта

## Цель

Клиент проходит психологические опросники на `/s/{slug}/diagnostics/`, результаты сохраняются в БД и доступны клиенту (история) и специалисту (карточка клиента).

Референс по UX и методикам: [psytests.org](https://psytests.org) — шкалы, профили, расшифровка по полосам.

## Поток

1. Клиент залогинен → «Перейти к диагностике» / «Пройти»
2. Хаб: список тестов + история прохождений
3. Прохождение → POST submit → `diagnostic_attempts`
4. Страница результата с шкалами (полосы / профиль)

## Тесты (каталог)

| Код | Название | Статус | psytests |
|-----|----------|--------|----------|
| `bhs` | Шкала безнадёжности Бека | ✅ полная | [bhi-run](https://psytests.org/depr/bhi-run.html) |
| `bdi` | Шкала депрессии Бека | ✅ полная | [bdi](https://psytests.org/depr/bdi.html) |
| `wcq` | Способы совладания | ✅ краткая форма (32 пункта, 8 шкал) | [wcq](https://psytests.org/coping/wcq.html) |
| `schmischek` | Акцентуации Шмишек | ✅ краткая форма (40 пунктов, 10 шкал) | [shmi90acc](https://psytests.org/accent/shmi90acc.html) |
| `osop` | Стили воспитания | ✅ краткая форма (18 пунктов, 3 шкалы) | [osopFf](https://psytests.org/parent/osopFf.html) |
| `rmet` | Чтение эмоций по глазам | ⏳ нужны изображения | [eyespsy](https://psytests.org/emo/eyespsy.html) |

## БД

- `diagnostic_attempts` — попытки и JSON результатов
- `client_specialist_links` — связь клиент ↔ специалист
- `diagnostic_invitations` — персональные ссылки

Таблицы создаются при старте (`ensure_diagnostics_schema`). На submit — `ensure_diagnostics_write_ready` перед INSERT.

## Отображение (как psytests)

- **bands** — одна шкала, цветные диапазоны (BHS, BDI)
- **radar** — несколько шкал, столбцы с % заполнения (WCQ, Шмишек, OSOP)
- Ссылка «Методика на psytests.org» на карточке теста
- Дисклеймер: не диагноз, не замена консультации
