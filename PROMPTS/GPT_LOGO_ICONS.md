# Промпт для GPT / генератора картинок: логотип и иконки кабинета

Скопируй блок ниже в ChatGPT (или другой генератор изображений / GPT с canvas).

---

## Промпт

```
Ты senior brand / product designer. Сделай набор визуалов для SaaS записи клиентов «Все клиенты здесь» (allyourclients.ru).

Стиль референсов: Cal.com + GitHub + минималистичный кабинет (как Cursor empty state). НЕ purple neon, НЕ glassmorphism, НЕ 3D, НЕ фотореализм людей.

Цветовая система (строго одна гамма, адаптив light/dark):

Light:
- фон #FFFFFF / #FAFAFA
- текст #0A0A0A
- акцент (кнопки/активное) #111111
- muted #737373
- border #E5E5E5

Dark:
- фон #0A0A0A / #141414
- текст #FAFAFA
- акцент (кнопки/активное) #FAFAFA
- muted #A3A3A3
- border rgba(255,255,255,0.1)

Иконки должны хорошо читаться в ОБЕИХ темах: либо 1) монохром currentColor SVG (предпочтительно), либо 2) две версии light/dark. Без радуги, без брендовых цветов Telegram/VK/Yandex внутри UI-иконок кабинета (для интеграций тоже нейтральный монохром в стиле сайта; цвет бренда соцсетей только если явно попросим отдельно).

### 1) Логотип (не ломай идею бренда, предложи 3 варианта)
Форматы: SVG + PNG 512 и 1024, квадрат и горизонтальный lockup.
Варианты:
A) wordmark «Все клиенты здесь»
B) mark (простой геометрический знак записи/календаря) + wordmark
C) только mark для favicon / PWA 512

Стиль: Inter-like, геометрический, Cal.com-спокойный. Без градиентов и glow.

### 2) Иконки sidenav кабинета (обязательно набор 20x20 / 24x24 SVG, stroke 1.75–2px, round caps)
По одной иконке на пункт:
1. overview / home (обзор)
2. calendars
3. services
4. bookings / appointments
5. clients
6. profile
7. integrations
8. book (записаться)
9. my-bookings
10. telegram (нейтральный paper-plane, не синий бренд)
11. theme (sun/moon optional)
12. logout
13. external-site (на сайт)

Имена файлов латиницей: icon-overview.svg, icon-calendars.svg, …

### 3) Украшение empty state кабинета (правая панель)
Текст на экране (оставь место под него, не вшивай длинный текст в растр если можно слоями):
- Заголовок бренда: «Все клиенты здесь»
- Подзаголовок: «Кабинет специалиста. Выберите раздел слева: календари, услуги, записи или клиенты.»
- Подсказка: «Подсказка: начните с «Календари», чтобы открыть окна приёма.»

Сделай:
- декоративную композицию вокруг логотипа: тонкие линии / мягкая сетка календаря / пустой workspace как в Cursor
- варианты: light empty + dark empty (PNG 1600x1000 и SVG если возможно)
- логотип по центру крупно, вокруг спокойный орнамент без клипарта
- никаких разноцветных плашек дней

### 4) Выдача
Для каждого ассета:
- превью
- SVG исходник (для иконок обязательно)
- PNG @1x @2x
- краткая таблица: где ставить (favicon, header, sidenav, empty state, PWA)

Сначала покажи мудборд 4 кадра (logo / icons grid / empty light / empty dark), потом финальные файлы.
```

## Куда потом вставить в проект

| Ассет | Путь |
|-------|------|
| Логотип | `app/static/svg/logo.svg` (сейчас не трогаем, пока не утвердим) |
| Favicon / PWA | `app/static/svg/favicon.svg`, `brand/service-icon-512.svg` |
| Иконки меню | `app/static/svg/icons/*.svg` |
| Empty state (опц.) | `app/static/svg/cabinet-empty.svg` или фон в `cabinet-empty` |

После получения файлов: сказать Cursor «подключи новые иконки в `cabinet_sidenav.html` и укрась `.cabinet-empty`».
